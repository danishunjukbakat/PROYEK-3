# DevKampus D3TI — Landing Page Interaktif

Landing page interaktif berbasis web modern yang dibangun menggunakan HTML5 Semantik, CSS3, dan Vanilla JavaScript (ES6+) tanpa framework eksternal. Tampilan dirancang dengan pendekatan minimalis, fokus pada keterbacaan, serta aksesibilitas.

## Fitur Utama

1. Mode Gelap & Terang (Dark Mode Toggle)
   Mengubah tema warna antarmuka secara dinamis menggunakan CSS Custom Properties.

2. Navigasi Mobile Responsif
   Menu navigasi yang dapat disesuaikan untuk tampilan layar ponsel dan tablet.

3. Filter Data Dinamis
   Penyajian daftar jadwal sesi secara dinamis dari JavaScript berdasarkan filter kategori topik.

4. Akordeon FAQ
   Komponen pertanyaan umum interaktif dengan dukungan atribut `aria-expanded` untuk pembaca layar.

5. Validasi Form Pendaftaran
   Pemeriksaan input nama, email, dan pilihan materi secara langsung sebelum pengiriman form.

6. Navigasi Kembali ke Atas
   Tombol melayang otomatis yang muncul saat halaman digulir ke bawah.

## Teknologi yang Digunakan

* HTML5: Struktur dokumen semantik tanpa framework.
* CSS3: Flexbox, Grid Layout, Media Queries, dan CSS Variables.
* JavaScript: Manipulasi DOM, Event Handling, dan Array Filtering.
